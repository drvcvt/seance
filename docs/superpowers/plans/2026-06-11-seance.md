# seance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A pure-Elisp ACP client (`seance`) that runs Codex inside Emacs: streaming chat buffer, gated/auto change review, buffer-aware file access, and a live-eval MCP bridge into the running Emacs.

**Architecture:** Emacs spawns the `@zed-industries/codex-acp` adapter and speaks newline-delimited JSON-RPC (ACP) with it through an own thin transport (`seance-rpc.el`). UI layers (chat, review) consume callbacks from the protocol core (`seance-acp.el`). A batch-Emacs MCP server (`bin/seance-mcp-bridge.el`) forwards `emacs_*` tool calls into the running Emacs via `emacsclient`. All tests run headless (ERT) against a scripted mock ACP agent — zero tokens.

**Tech Stack:** Emacs 30 Elisp only. Built-ins: `json-parse-string`/`json-serialize`, `make-process`, ERT, `diff-mode`, `transient`, `server`/`emacsclient`. External at runtime only: the `codex-acp` adapter via `npx`.

**Spec:** `docs/superpowers/specs/2026-06-11-seance-design.md`

**Conventions for every task:**
- All elisp files start with `;;; <name>.el --- <desc> -*- lexical-binding: t; -*-` and end with `(provide '<name>)` + `;;; <name>.el ends here` (scripts in `bin/`, `tests/mock-agent.el`, `tests/rpc-echo.el` are scripts, not libraries: no `provide`).
- Run the full suite with `./scripts/test.sh`; run one file with `emacs -Q --batch -L . -L tests -l tests/seance-test-helpers.el -l tests/<file> -f ert-run-tests-batch-and-exit`.
- Commit after every green task. NEVER add a Co-Authored-By trailer (user rule).
- JSON gotchas (apply everywhere): JSON arrays must be Elisp **vectors** for `json-serialize`; parse with `:object-type 'plist`, so keys arrive as `:camelCase` keywords; never put a literal `nil` value inside a plist passed to `json-serialize` — use `:json-false` for false and `:null` for null.

;; Responds to any request with {"echo": <method>}. ndjson over stdio.
;; NOTE: send-string-to-terminal writes unbuffered; princ may be
;; block-buffered when stdout is a pipe.

```elisp
;;; seance-rpc.el --- ndjson JSON-RPC 2.0 over stdio -*- lexical-binding: t; -*-

;;; Commentary:
;; Thin JSON-RPC transport: newline-delimited JSON over a subprocess.
;; Supports requests with async callbacks, notifications both ways, and
;; ASYNC replies to incoming requests (handler receives a REPLY closure).

;;; Code:

(require 'cl-lib)
(require 'json)

(cl-defstruct (seance-rpc (:constructor seance-rpc--make))
  process
  (next-id 0)
  (pending (make-hash-table :test #'eql))
  handler   ; (fn METHOD PARAMS REPLY); REPLY: (funcall reply RESULT &optional ERROR)
  notifier  ; (fn METHOD PARAMS)
  on-exit
  (residue ""))

(defun seance-rpc--parse (line)
  (json-parse-string line :object-type 'plist
                     :null-object nil :false-object :json-false))

(defun seance-rpc--send (rpc msg)
  (process-send-string (seance-rpc-process rpc)
                       (concat (json-serialize msg) "\n")))

(defun seance-rpc-request (rpc method params callback)
  "Send request METHOD with PARAMS plist; CALLBACK gets (RESULT ERROR)."
  (let ((id (cl-incf (seance-rpc-next-id rpc))))
    (puthash id callback (seance-rpc-pending rpc))
    (seance-rpc--send rpc (append `(:jsonrpc "2.0" :id ,id :method ,method)
                                  (and params `(:params ,params))))
    id))

(defun seance-rpc-notify (rpc method params)
  (seance-rpc--send rpc (append `(:jsonrpc "2.0" :method ,method)
                                (and params `(:params ,params)))))

(defun seance-rpc--dispatch (rpc msg)
  (let ((id (plist-get msg :id))
        (method (plist-get msg :method)))
    (cond
     ((and method id)                   ; incoming request
      (funcall (seance-rpc-handler rpc) method (plist-get msg :params)
               (lambda (result &optional error)
                 (seance-rpc--send
                  rpc (if error
                          `(:jsonrpc "2.0" :id ,id :error ,error)
                        `(:jsonrpc "2.0" :id ,id :result ,(or result :null)))))))
     (method                            ; notification
      (funcall (seance-rpc-notifier rpc) method (plist-get msg :params)))
     (id                                ; response to our request
      (when-let* ((cb (gethash id (seance-rpc-pending rpc))))
        (remhash id (seance-rpc-pending rpc))
        (funcall cb (plist-get msg :result) (plist-get msg :error)))))))

(defun seance-rpc--filter (rpc string)
  (let* ((data (concat (seance-rpc-residue rpc) string))
         (lines (split-string data "\n")))
    (setf (seance-rpc-residue rpc) (car (last lines)))
    (dolist (line (butlast lines))
      (unless (string-empty-p line)
        (condition-case err
            (seance-rpc--dispatch rpc (seance-rpc--parse line))
          (error (message "seance-rpc: bad message dropped: %s"
                          (error-message-string err))))))))

(defun seance-rpc-start (command &rest opts)
  "Start subprocess COMMAND (list of strings); return a `seance-rpc'.
OPTS plist: :handler :notifier :on-exit :name."
  (let* ((rpc (seance-rpc--make
               :handler (or (plist-get opts :handler) #'ignore)
               :notifier (or (plist-get opts :notifier) #'ignore)
               :on-exit (plist-get opts :on-exit)))
         (proc (make-process
                :name (or (plist-get opts :name) "seance-rpc")
                :command command
                :connection-type 'pipe
                :coding 'utf-8-unix
                :noquery t
                :stderr (get-buffer-create " *seance-rpc-stderr*")
                :filter (lambda (_p s) (seance-rpc--filter rpc s))
                :sentinel (lambda (_p event)
                            (when-let* ((fn (seance-rpc-on-exit rpc)))
                              (funcall fn event))))))
    (setf (seance-rpc-process rpc) proc)
    rpc))

(defun seance-rpc-alive-p (rpc)
  (and rpc (seance-rpc-process rpc)
       (process-live-p (seance-rpc-process rpc))))

(defun seance-rpc-shutdown (rpc)
  (when (seance-rpc-alive-p rpc)
    (setf (seance-rpc-on-exit rpc) nil)
    (delete-process (seance-rpc-process rpc))))

(provide 'seance-rpc)
;;; seance-rpc.el ends here
```

;;; mock-agent.el --- scripted ACP agent for seance tests
;; Plays the agent side of ACP over stdio (ndjson). Scenario comes from
;; the SEANCE_MOCK_SCENARIO env var: echo | tools | permission | fs.

(require 'json)
(require 'cl-lib)

(defvar mock-scenario (or (getenv "SEANCE_MOCK_SCENARIO") "echo"))
(defvar mock-next-id 1000)
(defvar mock-pending nil)  ; alist: our-request-id -> continuation (fn RESULT)

(defun mock-send (msg)
  (send-string-to-terminal (concat (json-serialize msg) "\n")))

(defun mock-result (id result)
  (mock-send `(:jsonrpc "2.0" :id ,id :result ,result)))

(defun mock-update (sid update)
  (mock-send `(:jsonrpc "2.0" :method "session/update"
               :params (:sessionId ,sid :update ,update))))

(defun mock-request (method params k)
  "Send a request to the client; call K with the result when it answers."
  (let ((id (cl-incf mock-next-id)))
    (push (cons id k) mock-pending)
    (mock-send `(:jsonrpc "2.0" :id ,id :method ,method :params ,params))))

(defun mock-end-turn (id)
  (mock-result id '(:stopReason "end_turn")))

(defun mock-prompt-text (params)
  (plist-get (aref (plist-get params :prompt) 0) :text))

(defun mock-run-scenario (id sid params)
  (pcase mock-scenario
    ("echo"
     (mock-update sid `(:sessionUpdate "agent_message_chunk"
                        :content (:type "text"
                                  :text ,(concat "echo: " (mock-prompt-text params)))))
     (mock-end-turn id))
    ("tools"
     (mock-update sid '(:sessionUpdate "tool_call" :toolCallId "tc-1"
                        :title "edit hello.el" :kind "edit" :status "pending"))
     (mock-update sid '(:sessionUpdate "tool_call_update" :toolCallId "tc-1"
                        :status "completed"
                        :content [(:type "diff" :path "hello.el"
                                   :oldText "old line\n" :newText "new line\n")]))
     (mock-update sid '(:sessionUpdate "plan"
                        :entries [(:content "step one" :priority "high" :status "completed")
                                  (:content "step two" :priority "high" :status "pending")]))
     (mock-update sid '(:sessionUpdate "agent_message_chunk"
                        :content (:type "text" :text "done")))
     (mock-end-turn id))
    ("permission"
     (mock-request
      "session/request_permission"
      `(:sessionId ,sid
        :toolCall (:toolCallId "tc-p1" :title "edit guarded.el" :kind "edit"
                   :content [(:type "diff" :path "guarded.el"
                              :oldText "before\n" :newText "after\n")])
        :options [(:optionId "opt-allow" :name "Allow" :kind "allow_once")
                  (:optionId "opt-allow-always" :name "Always" :kind "allow_always")
                  (:optionId "opt-reject" :name "Reject" :kind "reject_once")])
      (lambda (result)
        (let ((opt (plist-get (plist-get result :outcome) :optionId)))
          (mock-update "mock-session"
                       `(:sessionUpdate "agent_message_chunk"
                         :content (:type "text" :text ,(concat "picked: " opt))))
          (mock-end-turn (get 'mock-state 'prompt-id)))))
     (put 'mock-state 'prompt-id id))
    ("fs"
     ;; prompt text is a file path: read it via the client, write it back
     ;; uppercased, echo the original content.
     (let ((path (mock-prompt-text params)))
       (mock-request
        "fs/read_text_file" `(:sessionId ,sid :path ,path)
        (lambda (result)
          (let ((content (plist-get result :content)))
            (mock-request
             "fs/write_text_file"
             `(:sessionId ,sid :path ,path :content ,(upcase content))
             (lambda (_)
               (mock-update "mock-session"
                            `(:sessionUpdate "agent_message_chunk"
                              :content (:type "text" :text ,(concat "read: " content))))
               (mock-end-turn (get 'mock-state 'prompt-id)))))))
       (put 'mock-state 'prompt-id id)))))

(defun mock-handle (msg)
  (let ((id (plist-get msg :id))
        (method (plist-get msg :method)))
    (cond
     ;; response to one of OUR requests
     ((and id (not method))
      (when-let* ((entry (assq id mock-pending)))
        (setq mock-pending (delq entry mock-pending))
        (funcall (cdr entry) (plist-get msg :result))))
     ((equal method "initialize")
      (mock-result id '(:protocolVersion 1
                        :agentCapabilities (:loadSession :json-false))))
     ((equal method "session/new")
      (mock-result id '(:sessionId "mock-session")))
     ((equal method "session/prompt")
      (mock-run-scenario id (plist-get (plist-get msg :params) :sessionId)
                         (plist-get msg :params)))
     (id (mock-result id :null)))))

(while t
  (let ((line (condition-case nil (read-from-minibuffer "")
                (error (kill-emacs 0)))))
    (when (> (length line) 0)
      (mock-handle (json-parse-string line :object-type 'plist
                                      :null-object nil :false-object :json-false)))))

;;; seance-acp.el --- ACP protocol core -*- lexical-binding: t; -*-

;;; Commentary:
;; Owns the adapter subprocess and the ACP session lifecycle. No UI here:
;; consumers register :on-update / :on-status callbacks.

;;; Code:

(require 'cl-lib)
(require 'seance)
(require 'seance-rpc)

(defvar seance-acp--fs-read-function nil
  "When set, (fn PATH) -> string; serves fs/read_text_file. Set in Task 8.")
(defvar seance-acp--fs-write-function nil
  "When set, (fn PATH CONTENT); serves fs/write_text_file. Set in Task 8.")
(defvar seance-acp--permission-function nil
  "When set, (fn SESSION PARAMS REPLY); serves session/request_permission.
Set in Task 7. Until then requests are answered with the first option.")
(defvar seance-acp--mcp-servers-function nil
  "When set, (fn) -> vector of MCP server specs for session/new. Task 12.")

(cl-defstruct (seance-acp-session (:constructor seance-acp-session--make))
  rpc id cwd
  (permission-mode seance-permission-mode)
  (status 'connecting)
  (preamble-sent nil)
  on-update    ; (fn UPDATE-PLIST)
  on-status)   ; (fn STATUS-SYMBOL)

(defvar seance-acp--session nil
  "The current (single, v1) session.")

(defun seance-acp--set-status (sess status)
  (setf (seance-acp-session-status sess) status)
  (when-let* ((fn (seance-acp-session-on-status sess)))
    (funcall fn status)))

(defun seance-acp-connect (cwd &rest opts)
  "Spawn the adapter and open an ACP session rooted at CWD.
OPTS: :on-update :on-status :on-ready (each optional)."
  (let* ((sess (seance-acp-session--make
                :cwd (expand-file-name cwd)
                :on-update (plist-get opts :on-update)
                :on-status (plist-get opts :on-status)))
         (rpc (seance-rpc-start
               seance-codex-acp-command
               :name "seance-acp"
               :notifier (lambda (method params)
                           (seance-acp--notification sess method params))
               :handler (lambda (method params reply)
                          (seance-acp--client-request sess method params reply))
               :on-exit (lambda (_event)
                          (seance-acp--set-status sess 'disconnected)))))
    (setf (seance-acp-session-rpc sess) rpc)
    (seance-rpc-request
     rpc "initialize"
     '(:protocolVersion 1
       :clientCapabilities (:fs (:readTextFile t :writeTextFile t)))
     (lambda (_result error)
       (if error
           (seance-acp--set-status sess 'error)
         (seance-rpc-request
          rpc "session/new"
          `(:cwd ,(seance-acp-session-cwd sess)
            :mcpServers ,(if seance-acp--mcp-servers-function
                             (funcall seance-acp--mcp-servers-function)
                           []))
          (lambda (result error)
            (if error
                (seance-acp--set-status sess 'error)
              (setf (seance-acp-session-id sess)
                    (plist-get result :sessionId))

;; Gated mode: every session/request_permission opens a diff side window

(defun seance-review--pick-option (options &rest kinds)
  "Return the optionId of the first option matching any of KINDS, in order."
  (catch 'found
    (dolist (kind kinds)
      (seq-doseq (opt options)
        (when (equal (plist-get opt :kind) kind)
          (throw 'found (plist-get opt :optionId)))))
    ;; final fallback: first option
    (plist-get (aref options 0) :optionId)))

(defun seance-review--outcome (option-id)
  `(:outcome (:outcome "selected" :optionId ,option-id)))

(defun seance-review-handle-permission (sess params reply)
  "ACP session/request_permission entry point."
  (if (eq (seance-acp-session-permission-mode sess) 'auto)
      (funcall reply (seance-review--outcome
                      (seance-review--pick-option
                       (plist-get params :options)
                       "allow_once" "allow_always")))
    (seance-review--show-permission sess params reply)))

(defun seance-review--permission-text (tool-call)
  "Human-readable description + diff for TOOL-CALL."
  (concat
   (format "Codex requests: %s\n\n" (or (plist-get tool-call :title) "tool call"))
   (mapconcat
    (lambda (item)
      (pcase (plist-get item :type)
        ("diff" (seance-diff-strings (or (plist-get item :oldText) "")
                                     (or (plist-get item :newText) "")
                                     (plist-get item :path)))
        (_ (format "%S\n" item))))
    (append (plist-get tool-call :content) nil)
    "\n")))

(defun seance-review--show-permission (sess params reply)
  (let ((buf (get-buffer-create seance-review-permission-buffer)))
    (with-current-buffer buf
      (let ((inhibit-read-only t))
        (erase-buffer)
        (insert (seance-review--permission-text (plist-get params :toolCall)))

        (seance-keys-apply seance-keys-permission-table
                           (setq-local seance-review--map
                                       (copy-keymap diff-mode-map)))
        (use-local-map seance-review--map)
        (define-key seance-review--map (kbd "?") #'seance-permission-help)
        (setq buffer-read-only t)
        (setq seance-review--reply reply
              seance-review--options (plist-get params :options)
              seance-review--session sess)))
    (display-buffer buf '(display-buffer-in-side-window (side . right)))))

        (id (apply #'seance-review--pick-option seance-review--options kinds)))

      (quit-window nil win))
    (funcall reply (seance-review--outcome id))))

;;; seance-bridge.el --- emacs_* tools dispatched from the MCP bridge -*- lexical-binding: t; -*-

;;; Commentary:
;; `seance-bridge-dispatch' is invoked via `emacsclient --eval' by
;; bin/seance-mcp-bridge.el. It returns a JSON string (:ok BOOL :value
;; STRING) so transport errors and tool errors stay distinguishable.

;;; Code:

(require 'json)
(require 'seance)

(defun seance-bridge--permission-mode ()
  "Effective permission mode: the active session's, else the defcustom."
  (if (and (boundp 'seance-acp--session) seance-acp--session)
      (seance-acp-session-permission-mode seance-acp--session)
    seance-permission-mode))

(defun seance-bridge-dispatch (tool args-json)
  "Run TOOL with ARGS-JSON (a JSON object string or nil); return JSON string."
  (condition-case err
      (let ((args (and args-json (not (string-empty-p args-json))
                       (json-parse-string args-json :object-type 'plist
                                          :null-object nil :false-object nil))))
        (json-serialize `(:ok t :value ,(seance-bridge--run tool args))))
    (error (json-serialize `(:ok :json-false
                             :value ,(error-message-string err))))))

(defun seance-bridge--run (tool args)
  (pcase tool
    ("emacs_eval" (seance-bridge--eval (plist-get args :form)))
    ("emacs_buffer_list" (seance-bridge--buffer-list))
    ("emacs_buffer_get" (seance-bridge--buffer-get (plist-get args :name)))
    ("emacs_describe" (seance-bridge--describe (plist-get args :symbol)))
    ("emacs_state" (seance-bridge--state))
    (_ (error "Unknown tool: %s" tool))))

(defun seance-bridge--eval (form-string)
  (unless form-string (error "emacs_eval needs a :form argument"))
  (when (eq (seance-bridge--permission-mode) 'gated)
    (unless (y-or-n-p (format "seance: Codex wants to eval %s — allow? "
                              (truncate-string-to-width form-string 80 nil nil "…")))
      (error "User denied evaluation")))
  (format "%S" (eval (read form-string) t)))

(defun seance-bridge--buffer-list ()
  (mapconcat
   (lambda (b)
     (with-current-buffer b
       (format "%s | %s | %s%s"
               (buffer-name) major-mode
               (or (buffer-file-name) "no file")
               (if (buffer-modified-p) " [modified]" ""))))
   (buffer-list) "\n"))

(defun seance-bridge--buffer-get (name)
  (let ((buf (get-buffer (or name ""))))
    (unless buf (error "No such buffer: %s" name))
    (with-current-buffer buf
      (buffer-substring-no-properties (point-min) (point-max)))))

(defun seance-bridge--describe (name)
  (let ((sym (intern-soft (or name ""))))
    (unless sym (error "Unknown symbol: %s" name))
    (let ((parts nil))
      (when (fboundp sym)
        (push (format "Function: %s\nDoc: %s%s"
                      (ignore-errors (prin1-to-string (func-arity sym)))
                      (or (ignore-errors (documentation sym)) "(no doc)")
                      (if-let* ((loc (ignore-errors
                                       (find-lisp-object-file-name
                                        sym (symbol-function sym)))))
                          (format "\nDefined in: %s" loc)
                        ""))
              parts))
      (when (boundp sym)
        (push (format "Variable value: %S\nDoc: %s"
                      (symbol-value sym)
                      (or (documentation-property sym 'variable-documentation)
                          "(no doc)"))
              parts))
      (unless parts (error "%s is neither bound nor fbound" name))
      (string-join (nreverse parts) "\n\n"))))

(defun seance-bridge--state ()
  (format "Emacs %s%s\nSelected buffer: %s (%s)\nseance source: %s\nRecent *Messages*:\n%s"
          emacs-version
          (if (boundp 'doom-version) (format " / Doom %s" doom-version) "")
          (buffer-name (window-buffer (selected-window)))
          (with-current-buffer (window-buffer (selected-window)) major-mode)
          (file-name-directory (locate-library "seance"))
          (if-let* ((msgs (get-buffer "*Messages*")))
              (with-current-buffer msgs
                (buffer-substring-no-properties

;;; seance-mcp-bridge.el --- MCP stdio server bridging into a running Emacs
;; Usage: emacs --batch --script bin/seance-mcp-bridge.el
;; Env: SEANCE_SERVER = name of the Emacs server socket (default "server").
;; Speaks MCP (ndjson JSON-RPC) on stdio; forwards tools/call to the
;; running Emacs via emacsclient --eval (seance-bridge-dispatch ...).

(require 'json)

(defvar bridge-server (or (getenv "SEANCE_SERVER") "server"))

(defconst bridge-tools
  '[(:name "emacs_eval"
     :description "Evaluate an Emacs Lisp form in the user's RUNNING Emacs and return the printed result. Use this to test code live, reload changed files with (load ...), or inspect editor state."
     :inputSchema (:type "object"
                   :properties (:form (:type "string"
                                       :description "An Elisp form, e.g. (buffer-name)"))
                   :required ["form"]))
    (:name "emacs_buffer_list"
     :description "List all live buffers in the running Emacs: name, major mode, visited file, modified flag."
     :inputSchema (:type "object"))
    (:name "emacs_buffer_get"
     :description "Return the full text content of a named buffer in the running Emacs (including unsaved changes)."
     :inputSchema (:type "object"
                   :properties (:name (:type "string" :description "Buffer name"))
                   :required ["name"]))
    (:name "emacs_describe"
     :description "Documentation, arity and source location for an Emacs Lisp function or variable, like describe-function/describe-variable."
     :inputSchema (:type "object"
                   :properties (:symbol (:type "string" :description "Symbol name, e.g. find-file"))
                   :required ["symbol"]))
    (:name "emacs_state"
     :description "Snapshot of the running Emacs: version, selected buffer and mode, seance source location, recent *Messages*."
     :inputSchema (:type "object"))])

(defun bridge-send (msg)
  (send-string-to-terminal (concat (json-serialize msg) "\n")))

(defun bridge-emacsclient (tool args-json)
  "Forward TOOL/ARGS-JSON into the running Emacs; return parsed result plist."
  (with-temp-buffer
    (let ((status (call-process "emacsclient" nil t nil
                                "-s" bridge-server "--eval"
                                (format "(seance-bridge-dispatch %S %S)"
                                        tool (or args-json "")))))
      (unless (eql status 0)
        (error "emacsclient failed (%s): %s" status (buffer-string)))
      ;; emacsclient prints the elisp value: a quoted string containing JSON
      (json-parse-string (car (read-from-string (buffer-string)))
                         :object-type 'plist
                         :null-object nil :false-object nil))))

(defun bridge-handle (msg)
  (let ((id (plist-get msg :id))
        (method (plist-get msg :method))
        (params (plist-get msg :params)))
    (pcase method
      ("initialize"
       (bridge-send
        `(:jsonrpc "2.0" :id ,id
          :result (:protocolVersion "2025-06-18"
                   :capabilities (:tools (:listChanged :json-false))
                   :serverInfo (:name "seance-emacs" :version "0.1.0")))))
      ("notifications/initialized" nil)
      ("tools/list"
       (bridge-send `(:jsonrpc "2.0" :id ,id :result (:tools ,bridge-tools))))
      ("tools/call"
       (condition-case err
           (let* ((args (plist-get params :arguments))
                  (res (bridge-emacsclient (plist-get params :name)
                                           (and args (json-serialize args)))))
             (bridge-send
              `(:jsonrpc "2.0" :id ,id
                :result (:content [(:type "text" :text ,(or (plist-get res :value) ""))]
                         :isError ,(if (eq (plist-get res :ok) t) :json-false t)))))
         (error
          (bridge-send
           `(:jsonrpc "2.0" :id ,id
             :result (:content [(:type "text" :text ,(error-message-string err))]
                      :isError t))))))
      (_ (when id
           (bridge-send `(:jsonrpc "2.0" :id ,id
                          :error (:code -32601 :message "Method not found"))))))))

(while t
  (let ((line (condition-case nil (read-from-minibuffer "")
                (error (kill-emacs 0)))))
    (when (> (length line) 0)
      (bridge-handle (json-parse-string line :object-type 'plist
                                        :null-object nil :false-object :json-false)))))
